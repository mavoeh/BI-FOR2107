# FOR2107 resting-state comparison presentation

Compile from this directory with:

```bash
latexmk -pdf presentation.tex
```

The deck compares the local Tozzi supplementary panels with the cached FOR2107 resting-state reproductions for `k=6` and `k=5`. The paper panels are extracted from `literature/2024_tozzi_suppl.pdf`; the current panels are generated outputs and use the 14 resting-state connectivity features.
